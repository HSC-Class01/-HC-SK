# 유한양행 DART API 기반 재무분석 및 GitHub 대시보드 구축

## 1. 프로젝트 개요

본 프로젝트는 금융감독원 전자공시시스템(DART)의 Open API를 활용하여
유한양행의 재무제표 데이터를 수집하고, 주요 재무비율을 계산·분석하는
것을 목적으로 한다. 분석 결과와 데이터 처리 과정을 GitHub에 저장하고,
기업의 재무상태와 경영성과를 확인할 수 있는 대시보드를 구축한다.

## 2. 프로젝트 정보

-   **작성자:** 방희철
-   **분석 대상:** 유한양행
-   **종목코드:** 000100
-   **데이터 출처:** 금융감독원 DART Open API
-   **API 주소:** https://opendart.fss.or.kr/
-   **개발 및 데이터 처리:** Python
-   **버전 관리 및 대시보드 공유:** GitHub

## 3. 주요 수행 내용

1.  DART Open API를 이용해 유한양행의 사업보고서 및 재무제표 데이터를
    수집한다.
2.  수집한 데이터를 정리하고 분석에 적합한 형태로 가공한다.
3.  재무제표 및 재무비율 실무 가이드를 참고하여 주요 재무비율을
    계산한다.
4.  계산 결과를 바탕으로 기업의 안정성, 수익성, 성장성 및 활동성을
    분석한다.
5.  수집 데이터와 분석 코드를 GitHub 저장소에 관리한다.
6.  분석 결과를 시각화하여 기업의 재무상태와 경영성과를 확인할 수 있는
    대시보드를 구성한다.

## 4. 분석 항목

-   **안정성:** 부채비율, 자기자본비율 등
-   **수익성:** 매출액영업이익률, 총자산순이익률(ROA),
    자기자본순이익률(ROE) 등
-   **성장성:** 매출액 증가율, 영업이익 증가율 등
-   **활동성:** 총자산회전율 등

※ 실제 분석 항목과 계산 방식은 확보한 재무 데이터 및 참고 가이드의
정의에 따라 확정한다.

## 5. 사용 기술 및 데이터 관리

-   Python을 이용한 API 요청, 데이터 수집 및 가공
-   재무비율 계산 및 분석 결과 저장
-   GitHub를 이용한 코드와 문서의 버전 관리
-   대시보드를 통한 분석 결과 시각화

## 6. API 인증키 보안

DART API 인증키는 코드나 README에 직접 작성하지 않는다. GitHub의 저장소
비밀 정보(Repository secrets)에 `DART_API_KEY`라는 이름으로 저장하고,
실행 환경에서 불러와 사용한다.

**주의:** 인증키가 포함된 파일을 공개 저장소에 업로드하지 않는다.

## 7. 기대 효과

본 프로젝트를 통해 공시 데이터를 활용한 재무분석 과정을 실습하고,
재무비율을 바탕으로 유한양행의 재무상태와 경영성과를 체계적으로
파악한다. 또한 데이터 수집부터 분석 및 시각화까지의 과정을 GitHub에
정리하여 재현 가능하고 확인하기 쉬운 결과물을 구축한다.
